# Security

Report credential exposure or a security vulnerability privately to
[support@flashdata.dev](mailto:support@flashdata.dev). Do not place API keys, storage
credentials, signed URLs or private media details in public issues.

The toolkit sends your destination credentials to FlashData for cloud delivery. Keep
configuration on your server or development machine. Checkpoints store only IDs and
workflow information. Restrict access to your result exports according to their content.

The initial supported release is 0.1.x. Update the `flashdata` dependency within its
documented compatibility range when SDK fixes become available.
